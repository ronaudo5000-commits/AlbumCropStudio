# AlbumCrop Studio

[English](../README.md) | [日本語](README_ja.md) | [繁體中文](README_zh_TW.md)

從「資料」到「資源」，再到「資產」

AlbumCrop Studio 是一款桌面應用程式，用於從掃描的相簿頁面及其他典藏影像資料中偵測並裁切個別照片。

它不只是照片裁切工具，也希望成為整理、保存、再利用與分享歷史照片紀錄的起點。

此儲存庫包含 AlbumCrop Studio 的免費版本 **AlbumCrop Studio Free**。

## 目前穩定版本

`0.11.0`

主要開發分支可能包含尚未納入最新穩定版本的功能與改進。

## Free 版限制

AlbumCrop Studio Free 主要面向個人使用與小規模數位典藏工作流程。

Free 版有以下限制：

- 一次最多載入 **5 頁**
- PDF 的每一頁都會計入 5 頁上限
- Free 版無法開啟超過 5 頁的專案檔案
- 一次只能匯出 **一個選取頁面**
- 該頁面的所有裁切框可一次一起匯出

在這些限制內，仍可使用裁切框編輯、自動偵測、專案儲存、復原支援、馬賽克處理及其他核心功能。

## 功能

### 載入與頁面管理

- 載入影像檔案與 PDF 文件
- 在 Free 版 5 頁限制內處理多頁資料
- 在縮圖顯示與精簡顯示之間切換頁面清單
- 選擇一頁作為匯出對象
- 刪除頁面並使用 Undo 復原
- 快取最近瀏覽的頁面以加快切換速度

### 裁切框

- 自動偵測掃描相簿頁面中的照片
- 手動建立裁切框
- 移動、調整大小、複製、旋轉及刪除個別裁切框
- 選取多個裁切框
- 使用 Ctrl+A 選取目前頁面的所有裁切框
- 一次移動或刪除多個選取的裁切框
- 保留相對配置來複製、剪下及貼上多個裁切框
- 在同一工作階段的不同頁面之間複製或移動裁切框配置
- 將裁切框配置貼到選取頁面或其他所有已載入頁面
- 當來源頁面與目的頁面尺寸不同時，按比例縮放貼上的裁切框配置
- 將裁切框配置貼到其他頁面時保留既有馬賽克區域
- 編輯操作支援 Undo / Redo
- 多頁裁切框貼上操作支援 Undo / Redo

### 對齊與等距分布

可從右鍵選單對多個獨立裁切框進行對齊或等距分布。

可用的對齊操作：

- 靠左對齊
- 水平置中
- 靠右對齊
- 靠上對齊
- 垂直置中
- 靠下對齊

可用的分布操作：

- 水平等距分布
- 垂直等距分布

對齊至少需要 2 個獨立裁切框。

等距分布至少需要 3 個獨立裁切框。

群組框與馬賽克區域會與這些操作分開管理。

### 裁切框群組

- 將多個裁切框群組化
- 編輯群組內的個別裁切框
- 取消群組
- 切換頁面後保留群組資訊
- 將群組資訊儲存在專案檔案中
- 將群組裁切框匯出為單一合成影像

### 長寬比

- 為每個裁切框設定長寬比模式
- 自由調整大小
- 保留目前比例
- 使用 16:9、9:16、4:3、3:2、1:1 預設
- 調整大小時按住 Shift，可暫時保留目前比例
- 切換頁面後保留長寬比設定
- Undo / Redo 後保留長寬比設定
- 在專案檔案中保留長寬比設定
- 匯出時保留長寬比設定
- 使用較小的調整大小控制點，方便操作彼此接近的裁切框

### 馬賽克區域

馬賽克區域提供一種輕量方式，可在匯出前遮蔽個人資訊或其他敏感內容。

- 建立長方形馬賽克區域
- 同一頁面可建立多個馬賽克區域
- 移動與調整馬賽克區域大小
- 刪除馬賽克區域
- 馬賽克區域編輯支援 Undo / Redo
- 每頁分別儲存
- 切換頁面後保留
- 在專案檔案中儲存與復原
- 刪除頁面後再以 Undo 復原時仍保留
- 匯出前可預覽馬賽克效果
- 匯出 JPEG 時套用馬賽克
- 可正確套用於一般、旋轉與群組裁切框

馬賽克區域與裁切框分開管理。

因此，**馬賽克區域不會跟隨裁切框配置一起複製或貼上**。這可避免同一遮蔽區域被誤套用到大量無關影像。

### 預覽與導覽

- 將裁切結果縮放至右側預覽區可完整查看的大小
- 在裁切預覽中查看馬賽克效果
- 按一下裁切預覽即可開啟放大檢視
- 使用上一個 / 下一個控制項切換放大預覽
- 使用左右方向鍵切換放大預覽
- 在放大預覽中縮放與平移
- 使用滑鼠中鍵平移主畫布
- 使用 Space + 左鍵拖曳平移主畫布
- 使用動畫邊框顯示目前選取的裁切框

### 匯出

- 設定輸出 DPI
- 以毫米設定裁切邊距
- 設定 JPEG 品質
- 將選取頁面上的所有裁切框匯出為 JPEG
- 匯出時顯示百分比與已處理 / 總數
- 在匯出檔名中保留原始頁碼
- 匯出後保留裁切框
- 覆寫既有檔案前先確認
- 匯出旋轉裁切框
- 匯出群組裁切框
- 匯出時套用馬賽克處理

## 專案檔案

AlbumCrop Studio 可將目前工作儲存為專案檔案。

專案中可包含：

- 已載入頁面
- 裁切框位置
- 裁切框大小
- 旋轉角度
- 每個裁切框的長寬比模式
- 裁切框群組資訊
- 馬賽克區域位置與大小
- 頁面匯出選取狀態
- 輸出設定

長寬比模式會針對每個裁切框分別儲存。

在加入長寬比或馬賽克資訊之前建立的舊專案仍可相容。沒有儲存比例資訊的裁切框會以自由調整模式開啟，沒有馬賽克資訊的舊專案則會在沒有馬賽克區域的狀態下開啟。

AlbumCrop Studio 在開啟專案時也會檢查專案格式版本。

使用較新且目前不支援格式的專案不會被開啟。這可避免使用較舊版本 AlbumCrop Studio 時意外遺失較新的專案資料。

儲存專案時，AlbumCrop Studio 會先寫入暫存檔，再取代原本的儲存檔案。這可降低儲存過程中斷時損壞既有專案的風險。

AlbumCrop Studio Free 最多可開啟 5 頁的專案。

超過 5 頁的專案不會在 Free 版中開啟，以避免只載入或覆寫大型專案的一部分。

重新開啟專案時，請讓原始影像與 PDF 保持在原本位置。

## 自動儲存與當機復原

AlbumCrop Studio 可在專案有未儲存變更時，自動建立復原資料。

Auto Save 的用途是復原，不應取代一般專案儲存。

在以下情況下可能建立復原資料：

- 專案有未儲存的變更
- 至少載入一頁影像或 PDF
- 未執行照片自動偵測
- 未進行匯出
- 未進行多頁批次貼上

如果 AlbumCrop Studio 正常結束，暫時復原資料會被刪除。

如果應用程式或電腦意外停止，復原資料可能會保留至下次啟動。

若啟動時找到上一個工作階段的復原資料，可選擇：

- 復原
- 捨棄
- 取消

復原後的工作會以未儲存狀態開啟，讓使用者自行選擇儲存位置。

若復原需要的原始影像遺失，復原會停止，但復原資料會保留。將原始影像放回原本位置後即可再次嘗試。

無效的復原檔案會被跳過，不會阻止系統找到較舊但有效的復原資料。

可從以下位置開啟簡易快速開始指南：

## 從原始碼執行

### 1. 複製儲存庫

```bash
git clone https://github.com/ronaudo5000-commits/AlbumCropStudio.git
cd AlbumCropStudio
```

### 2. 建立虛擬環境

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. 安裝相依套件

```bash
python -m pip install -r requirements.txt
```

### 4. 啟動應用程式

```bash
python main.py
```

## 基本工作流程

1. 開啟影像或 PDF 文件。
2. 執行照片自動偵測，或手動建立裁切框。
3. 調整每個裁切框的位置、大小與旋轉角度。
4. 選擇自由調整、保留目前比例或預設長寬比。
5. 若要暫時保留目前比例，可在調整大小時按住 Shift。
6. 使用 Ctrl+點選來選取多個裁切框，或使用 Ctrl+A 選取目前頁面全部裁切框。
7. 若要一致排列多個獨立裁切框，可使用對齊或等距分布功能。
8. 使用 Ctrl+C 複製或 Ctrl+X 剪下，再使用 Ctrl+V 貼上並保留相對配置。
9. 需要時將裁切框配置複製或移動到其他頁面。
10. 若同一配置要套用到選取頁面或其他所有頁面，可使用多頁貼上。
11. 如果多個分離區域要視為單一輸出，可將裁切框群組化。
12. 若要調整群組內的個別框，使用群組框編輯模式。
13. 在需要遮蔽的內容上建立馬賽克區域。
14. 獨立調整馬賽克區域的位置與大小。
15. 處理多頁資料時，可在縮圖與精簡顯示模式間切換頁面清單。
16. 在右側預覽區確認裁切結果。
17. 需要較大檢視或更清楚確認馬賽克效果時，可按一下裁切預覽。
18. 使用上一個 / 下一個控制項或左右方向鍵切換放大預覽。
19. 在頁面清單中勾選一頁作為匯出對象。
20. 從主視窗或設定中調整 DPI、邊距與 JPEG 品質。
21. 選擇輸出資料夾。
22. 匯出選取頁面的所有裁切框。
23. 若要匯出其他頁面，請改選該頁後再次匯出。
24. 若要日後重複使用裁切框配置或其他工作內容，請儲存專案。

## 裁切框群組

如果多個分離區域需要匯出為單一合成影像，可以將多個裁切框群組化。

群組後的裁切框仍可使用 **群組框編輯** 模式個別調整。

取消群組後，這些裁切框會恢復獨立操作。

群組資訊會在頁面切換、專案儲存與載入，以及匯出時保留。

## 馬賽克區域

馬賽克區域是一項輕量的典藏支援功能，可用於遮蔽個人資訊或其他不應出現在匯出影像中的內容。

馬賽克區域：

- 為長方形
- 同一頁面可建立多個
- 可移動與調整大小
- 可刪除
- 支援 Undo / Redo
- 每頁分別儲存
- 可儲存在專案檔案中
- 會反映在裁切預覽中
- 匯出 JPEG 時會套用
- 可用於一般、旋轉與群組裁切框

馬賽克區域與裁切框分開管理。

因此，**不會跟隨裁切框配置一起複製或貼上**。這可避免同一遮蔽區域被意外套用到大量無關影像。

主畫布會將馬賽克區域顯示為可編輯的覆蓋框；裁切預覽與放大預覽則會顯示匯出時實際套用的馬賽克效果。

## 重要注意事項

處理重要或無法取代的典藏資料前：

- 保留原始檔案，不要修改
- 建立備份
- 將重要工作儲存為 AlbumCrop Studio 專案
- 使用樣本檔案測試輸出結果
- 正確性重要時，手動檢查匯出的照片
- 發布或分享前，確認馬賽克遮蔽範圍符合預期

自動偵測可能會因相簿版面、影像品質、背景、陰影、裝飾或頁面損壞而需要手動調整。

Auto Save 與 Crash Recovery 是安全功能，但不應視為一般專案儲存與外部備份的替代方案。

馬賽克處理只是視覺處理輔助功能，不能取代必要的法律、倫理、隱私或典藏審查。

## 已知限制

- Free 版一次最多載入 5 頁
- Free 版一次只能匯出一個選取頁面
- 自動偵測不一定能正確識別每一張照片
- 照片重疊時可能需要手動建立裁切框
- 裝飾邊框與頁面背景可能影響偵測

- 馬賽克區域是頁面專屬，不會包含在裁切框複製與貼上操作中
- 非常大的影像與 PDF 可能需要較多記憶體
- 僅有限快取最近查看的頁面
- macOS 尚未進行與 Windows 11 相同程度的測試
- AlbumCrop Studio Free 不包含進階中繼資料與地理位置功能

## 開發理念

AlbumCrop Studio 的目標不只是影像擷取。

長期目標是協助建立容易使用的數位典藏，支援歷史研究、國際協作，以及圍繞照片紀錄進行的對話。

應用程式以減少整理照片資料所需的時間與手動工作為核心，同時保留容易理解、可控制、可重現，且適合典藏工作的流程。

AlbumCrop Studio 的核心理念是：

**從「資料」到「資源」，再到「資產」。**

未來可能加入整理脈絡資訊、記錄不確定地點證據，以及支援其他媒體格式的工具。
