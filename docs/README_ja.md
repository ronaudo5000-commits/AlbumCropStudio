# AlbumCrop Studio

[English](../README.md) | [日本語](README_ja.md) | [繁體中文](README_zh_TW.md)

「資料」を「資源」に そして「資産」へ

AlbumCrop Studioは、スキャンしたアルバムページやその他のアーカイブ画像資料から、個々の写真を検出して切り抜くためのデスクトップアプリケーションです。

単なる写真切り抜きツールではなく、歴史的な写真記録を整理・保存・再利用・共有するための入口となることも目指しています。

このリポジトリには、AlbumCrop Studioの無料版である **AlbumCrop Studio Free** が含まれています。

## 現在の安定版

`0.11.0`

メインの開発ブランチには、最新の安定版にはまだ含まれていない機能や改善が含まれる場合があります。

## Free版の制限

AlbumCrop Studio Freeは、個人利用および小規模なデジタルアーカイブ作業を想定しています。

Free版には以下の制限があります。

- 一度に読み込めるのは最大 **5ページ**
- PDFは各ページを1ページとして数える
- 5ページを超えるプロジェクトファイルはFree版では開けない
- 書き出しは **一度に選択した1ページのみ**
- 選択したページ内のすべての切り抜き枠はまとめて書き出せる

この制限内では、切り抜き枠編集、自動検出、プロジェクト保存、復元機能、モザイク処理などの主要機能を利用できます。

## 主な機能

### 読み込みとページ管理

- 画像ファイルとPDF文書を読み込み
- Free版の5ページ制限内で複数ページを扱う
- ページ一覧をサムネイル表示とコンパクト表示で切り替え
- 書き出し対象ページを1ページ選択
- ページ削除とUndoによる復元
- 最近表示したページをキャッシュしてページ切り替えを高速化

### 切り抜き枠

- スキャンしたアルバムページ内の写真を自動検出
- 切り抜き枠を手動作成
- 個別の切り抜き枠を移動・リサイズ・コピー・回転・削除
- 複数の切り抜き枠を選択
- Ctrl+Aで現在ページのすべての切り抜き枠を選択
- 複数選択した切り抜き枠をまとめて移動・削除
- 相対配置を保ったまま複数の切り抜き枠をコピー・切り取り・貼り付け
- 同じ作業内の別ページへ切り抜き枠レイアウトをコピーまたは移動
- 選択ページまたは読み込み済みの他ページすべてへ切り抜き枠レイアウトを貼り付け
- 元ページと貼り付け先ページの寸法が異なる場合は比例変換
- 他ページへ貼り付ける際に既存のモザイク領域を保持
- 編集操作のUndo / Redo
- 複数ページへの切り抜き枠貼り付け操作のUndo / Redo

### 整列と等間隔配置

複数の独立した切り抜き枠を、右クリックメニューから整列または等間隔配置できます。

利用できる整列操作:

- 左揃え
- 左右中央揃え
- 右揃え
- 上揃え
- 上下中央揃え
- 下揃え

利用できる等間隔配置:

- 横方向に等間隔
- 縦方向に等間隔

整列には2個以上の独立した切り抜き枠が必要です。

等間隔配置には3個以上の独立した切り抜き枠が必要です。

グループ枠とモザイク領域は、これらの操作とは別に管理されます。

### 切り抜き枠グループ

- 複数の切り抜き枠をグループ化
- グループ内の個別切り抜き枠を編集
- グループ解除
- ページ切り替え後もグループ情報を保持
- プロジェクトファイルにグループ情報を保存
- グループ化した切り抜き枠を1枚の画像として書き出し

### アスペクト比

- 切り抜き枠ごとにアスペクト比モードを設定
- 自由リサイズ
- 現在の比率を維持
- 16:9、9:16、4:3、3:2、1:1 のプリセット
- リサイズ中にShiftを押して一時的に現在の比率を維持
- ページ切り替え後もアスペクト比設定を保持
- Undo / Redo後もアスペクト比設定を保持
- プロジェクトファイルにアスペクト比設定を保存
- 書き出し時にもアスペクト比設定を反映
- 密集した切り抜き枠を操作しやすい小型リサイズハンドル

### モザイク領域

モザイク領域は、個人情報やその他の機微情報を簡易的に隠してから書き出すための機能です。

- 長方形のモザイク領域を作成
- 同じページに複数のモザイク領域を作成
- モザイク領域を移動・リサイズ
- モザイク領域を削除
- モザイク領域編集のUndo / Redo
- ページごとに個別管理
- ページ切り替え後も保持
- プロジェクトファイルに保存・復元
- ページ削除後にUndoで復元した場合も保持
- 書き出し前にプレビューでモザイク効果を確認
- JPEG書き出し時にモザイクを適用
- 通常枠、回転枠、グループ枠にも正しく適用

モザイク領域は切り抜き枠とは独立して管理されます。

そのため、**切り抜き枠レイアウトのコピーや貼り付けには含まれません**。これにより、同じ隠し領域が無関係な画像へ誤って大量適用されることを防ぎます。

### プレビューとナビゲーション

- 切り抜き結果を右側のプレビュー領域に収まるよう表示
- プレビューでモザイク効果を確認
- 切り抜きプレビューをクリックして拡大表示
- 前へ / 次へで拡大プレビューを移動
- 左右矢印キーで拡大プレビューを移動
- 拡大プレビュー内でズームとパン
- 中ボタンでメインキャンバスをパン
- Space + 左ドラッグでメインキャンバスをパン
- 選択中の切り抜き枠をアニメーション枠で表示

### 書き出し

- 出力DPIを設定
- 切り抜き余白をミリメートル単位で設定
- JPEG品質を設定
- 選択した1ページ内のすべての切り抜き枠をJPEGで書き出し
- 書き出し進捗をパーセントと処理数 / 総数で表示
- 書き出しファイル名に元ページ番号を保持
- 書き出し後も切り抜き枠を保持
- 既存ファイルの上書き前に確認
- 回転した切り抜き枠を書き出し
- グループ枠を書き出し
- 書き出し時にモザイク処理を適用

## プロジェクトファイル

AlbumCrop Studioは、現在の作業内容をプロジェクトファイルとして保存できます。

保存される情報の例:

- 読み込み済みページ
- 切り抜き枠の位置
- 切り抜き枠のサイズ
- 回転角度
- 枠ごとのアスペクト比モード
- 切り抜き枠グループ情報
- モザイク領域の位置とサイズ
- ページごとの書き出し対象設定
- 出力設定

アスペクト比モードは切り抜き枠ごとに保存されます。

アスペクト比やモザイク情報が追加される以前に作成されたプロジェクトも互換性を保っています。アスペクト比情報のない枠は自由リサイズで開き、モザイク情報のない古いプロジェクトはモザイク領域なしで開きます。

AlbumCrop Studioは、プロジェクトを開く際にプロジェクト形式のバージョンも確認します。

現在のアプリより新しい未対応形式のプロジェクトは開きません。これにより、古いAlbumCrop Studioで新しいプロジェクトデータを誤って失うことを防ぎます。

プロジェクト保存では、一度一時ファイルへ書き込んでから既存ファイルを置き換えます。これにより、保存中に処理が中断された場合でも既存プロジェクトが破損するリスクを下げます。

AlbumCrop Studio Freeで開けるプロジェクトは最大5ページです。

5ページを超えるプロジェクトは、より大きなプロジェクトの一部だけを誤って読み込んだり上書きしたりすることを防ぐため、Free版では開きません。

プロジェクトを再度開く場合は、元の画像やPDFを元の場所に保持してください。

## 自動保存とクラッシュ復元

AlbumCrop Studioは、未保存の変更がある作業について復元用データを自動保存できます。

Auto Saveは通常のプロジェクト保存の代わりではなく、復旧を目的とした機能です。

復元データは以下のような条件で作成されます。

- プロジェクトに未保存の変更がある
- 画像またはPDFページが1ページ以上読み込まれている
- 写真の自動検出を実行していない
- 書き出し中ではない
- 複数ページへの一括貼り付け処理中ではない

AlbumCrop Studioが正常終了した場合、一時的な復元データは削除されます。

アプリやコンピューターが予期せず終了した場合は、復元データが次回起動時まで残ることがあります。

前回セッションの復元データが見つかった場合、以下を選択できます。

- 復元する
- 破棄する
- キャンセル

復元した作業は未保存の作業として開かれ、保存先をユーザーが選択できます。

復元に必要な元画像が見つからない場合は復元を中止し、復元データは保持します。元画像を元の場所へ戻した後、再度復元できます。

不正な復元ファイルはスキップされ、より古い正常な復元データの検出を妨げません。

## クイックスタート

軽量なクイックスタートガイドを以下から開けます。

**ヘルプ → クイックスタート**

ガイドでは基本的な流れを説明します。

1. 画像またはPDFを開く
2. 自動検出または手動配置で切り抜き枠を作る
3. 切り抜き枠を確認・調整する
4. プレビューを確認して切り抜き画像を書き出す
5. 必要に応じて作業をプロジェクトとして保存する

画像が読み込まれていない状態のメインキャンバスにも、画像やPDFを読み込み、切り抜き作業を開始するための簡単な案内を表示します。

クイックスタートは必要なときだけ開く方式で、起動時には自動表示されません。

## ソースから起動する

### 1. リポジトリをクローン

```bash
git clone https://github.com/ronaudo5000-commits/AlbumCropStudio.git
cd AlbumCropStudio
```

### 2. 仮想環境を作成

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. 依存パッケージをインストール

```bash
python -m pip install -r requirements.txt
```

### 4. アプリを起動

```bash
python main.py
```

## 基本的な作業の流れ

1. 画像またはPDF文書を開きます。
2. 写真の自動検出を実行するか、切り抜き枠を手動で作成します。
3. 各切り抜き枠の位置・大きさ・回転角度を調整します。
4. 自由リサイズ、現在比率の維持、またはプリセットのアスペクト比を選択します。
5. 一時的に現在の比率を維持したい場合は、リサイズ中にShiftを押します。
6. Ctrl+クリックで複数枠を選択するか、Ctrl+Aで現在ページのすべての切り抜き枠を選択します。
7. 複数の独立した切り抜き枠を揃えたい場合は、整列または等間隔配置を使用します。
8. Ctrl+Cでコピー、Ctrl+Xで切り取り、Ctrl+Vで相対配置を保ったまま貼り付けます。
9. 必要に応じて切り抜き枠レイアウトを別ページへコピーまたは移動します。
10. 同じ切り抜き枠レイアウトを選択ページや他のすべてのページへ適用する場合は複数ページ貼り付けを使います。
11. 複数の離れた領域を1つの出力として扱う場合は切り抜き枠をグループ化します。
12. グループ内の個別枠を調整する場合はグループ枠編集モードを使います。
13. 隠したい内容の上にモザイク領域を作成します。
14. モザイク領域の位置とサイズを切り抜き枠とは独立して調整します。
15. 複数ページを扱う場合はページ一覧をサムネイル表示またはコンパクト表示へ切り替えます。
16. 右側のプレビューで切り抜き結果を確認します。
17. より大きな表示やモザイク処理の確認が必要な場合は切り抜きプレビューをクリックします。
18. 前へ / 次へまたは左右矢印キーで拡大プレビューを移動します。
19. ページ一覧で書き出し対象を1ページ選択します。
20. メイン画面または設定画面でDPI・余白・JPEG品質を設定します。
21. 保存先フォルダを選択します。
22. 選択ページ内のすべての切り抜き枠を書き出します。
23. 別ページを書き出す場合は、そのページを書き出し対象にして再度実行します。
24. 切り抜き枠レイアウトなどの作業を再利用する場合はプロジェクトを保存します。

## 切り抜き枠グループ

離れた複数の領域を1枚の画像として書き出したい場合、複数の切り抜き枠をグループ化できます。

グループ化した切り抜き枠も、**グループ枠編集**モードを使えば個別に編集できます。

グループを解除すると、それぞれの枠を再び独立して操作できます。

グループ情報はページ切り替え、プロジェクト保存・読み込み、書き出し後も保持されます。

## モザイク領域

モザイク領域は、個人情報など、書き出した画像に含めたくない内容を隠すための軽量なアーカイブ支援機能です。

モザイク領域は以下に対応します。

- 長方形
- 同じページに複数作成
- 移動とリサイズ
- 削除
- Undo / Redo
- ページごとに個別保存
- プロジェクトファイルに保存
- 切り抜きプレビューに反映
- JPEG書き出し時に適用
- 通常枠、回転枠、グループ枠に対応

モザイク領域は切り抜き枠とは独立して管理されます。

そのため、**切り抜き枠レイアウトと一緒にはコピー・貼り付けされません**。これにより、同じ隠し領域を無関係な大量の画像へ誤適用することを避けられます。

メインキャンバスではモザイク領域を編集可能なオーバーレイ枠として表示し、切り抜きプレビューと拡大プレビューでは書き出し時に適用される実際のモザイク効果を表示します。

## 重要な注意事項

重要または代替不可能なアーカイブ資料を処理する前に:

- 元ファイルを変更せず保持する
- バックアップを作成する
- 重要な作業はAlbumCrop Studioのプロジェクトとして保存する
- サンプルファイルで出力を確認する
- 正確性が重要な場合は書き出した写真を目視確認する
- 公開・共有前にモザイク処理が意図した範囲を十分に覆っているか確認する

自動検出は、アルバムのレイアウト、画質、背景、影、装飾、ページの損傷などによって手動調整が必要になる場合があります。

Auto SaveとCrash Recoveryは安全性を高める機能ですが、通常のプロジェクト保存や外部バックアップの代わりにはなりません。

モザイク処理は視覚的な加工支援機能であり、必要な場合に行う法律・倫理・プライバシー・アーカイブ上の確認の代替にはなりません。

## 既知の制限

- Free版で一度に読み込めるのは最大5ページ
- Free版で一度に書き出せるのは選択した1ページ
- 自動検出ですべての写真を正しく検出できるとは限らない
- 写真同士が重なっている場合は手動で切り抜き枠を作成する必要がある場合がある
- 装飾的な枠やページ背景が検出結果に影響する場合がある
- モザイク領域は長方形のみ
- モザイク強度は現在固定
- モザイク領域はページ固有で、切り抜き枠のコピー・貼り付けには含まれない
- 非常に大きな画像やPDFでは多くのメモリを使用する場合がある
- 最近表示したページだけを限定的にメモリキャッシュする
- macOSはWindows 11と同等の検証をまだ行っていない
- 高度なメタデータ機能や位置情報機能はAlbumCrop Studio Freeには含まれていない

## 開発理念

AlbumCrop Studioは、単なる画像切り出し以上のものを目指しています。

長期的には、歴史研究、国際協働、写真記録をめぐる対話を支えられる、利用しやすいデジタルアーカイブ構築を支援することを目標としています。

写真資料の整理に必要な時間と手作業を減らしながら、理解しやすく、ユーザーが制御でき、再現可能で、アーカイブ作業に適したワークフローを維持することを重視しています。

AlbumCrop Studioの基本理念は、

**「資料」を「資源」に そして「資産」へ**

です。

将来的には、文脈情報の整理、不確かな位置情報の記録、他のメディア形式への対応などを検討しています。
